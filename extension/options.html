GH EXTENSIONS

A little more focus.

Compare complete release histories. Review the conversations that matter to you.

Your existing GitHub session

Compare pages and commit/PR details are read directly from github.com using the session in your GitHub tab. Sign in normally and complete organization SSO if required.

No personal access token, OAuth app, API access, or cookie-reading permission is required. This extension never reads your session cookie. The browser sends it to GitHub as part of normal same-origin page requests.

Only read-only page requests are made. Repository content stays in the current tab and is not stored or sent to another service.

Using review focus

Open a pull request’s Conversation or Files changed tab. Choose “Only these authors” or “Hide these authors”, enter usernames, and Apply. “Only mine” uses the signed-in GitHub username.

Include keeps threads started by the selected authors, with every reply. Exclude hides their threads and individual replies in other threads. The same filter is remembered across PRs and tabs. Reset shows everyone again.

Local filtering · No analytics · No third-party services
