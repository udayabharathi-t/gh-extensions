GitHub API access

Public comparisons work without a token, within GitHub’s anonymous rate limit. Private comparisons need a token with access to the repository.

Use a fine-grained token with Contents: read and Pull requests: read on the repositories you need. Your organization may require approval or SSO authorization.

The token is saved only in this browser’s extension storage, without browser sync. It is sent only to api.github.com. It is not encrypted by this extension. Comment filtering does not need a token.

Using review focus

Open a pull request’s Conversation or Files changed tab. Choose “Only these authors” or “Hide these authors”, enter usernames, and Apply. “Only mine” uses the signed-in GitHub username.

Include keeps threads started by the selected authors, with every reply. Exclude hides their threads and individual replies in other threads. The same filter is remembered across PRs and tabs. Reset shows everyone again.
